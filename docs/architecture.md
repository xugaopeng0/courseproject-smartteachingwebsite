# 架构与扩展边界

## 当前架构

浏览器 → nginx / React → Go API → PostgreSQL + 私有文件卷。

- **身份**：bcrypt 哈希；256 bit 随机会话；数据库只保存会话 token 的 SHA-256；8 小时过期；HttpOnly / SameSite=Lax cookie；退出立即删除服务器会话。
- **授权**：学生自注册；管理员创建教师；只有班级所有者可管理班级和文件。管理员不自动拥有课堂数据读取权限。
- **班级**：教师所有权 + 学生成员表；唯一邀请码；入班和归档使用行锁协调；成员退出或被移除后，下一次文件请求立即重新检查成员身份。
- **文件**：随机内部名称，原始文件名只用于元数据和下载响应。文件不通过静态目录暴露，PDF 与 Office 都经过同一授权 API。
- **部署**：三个容器；数据库和上传卷持久化；健康检查；服务端默认以非 root 用户运行；本地 HTTP 使用非 Secure cookie。

## 当前限制

适用于本机单实例部署。登录限流使用进程内计数，nginx 下以代理连接地址计数，因此属于整个平台的本地节流。公网/多实例部署时需引入可信代理配置和共享限流、HTTPS、文件病毒扫描、备份策略和密码恢复。文件格式签名校验不能证明 Office 文档无恶意宏。

数据库当前使用幂等初始化 SQL；后续字段变更应引入有版本号的迁移，不用修改建表语句假装迁移已有数据。数据库与上传卷需要成对备份。
