## 2. Bearer 令牌

- [x] 2.1 实现 `POST /api/auth/token`：校验账号密码后签发不透明令牌（`sessions` 表只存哈希），返回令牌与过期时间；错误凭证返回 401 且不区分“账号不存在/密码错误”。验证：HTTP 用例断言 200/401、返回字段与过期时间格式，并断言数据库只出现哈希、不出现原始令牌。
- [x] 2.2 `currentUser` 支持 `Authorization: Bearer`（先令牌后 Cookie），令牌过期、被登出撤销、用户已不是该班成员时都按未授权处理。验证：同一令牌在登出前后分别调用 `GET /api/auth/me`，断言 200 → 401；移除成员后调用班级接口断言 403。
- [x] 2.3 `route` 的同源校验只作用于 Cookie 身份：带 `Authorization` 的写请求跳过，带 Cookie 的写请求保持现有规则。验证：单元测试覆盖「仅令牌跨站来源放行」「仅 Cookie 跨站来源拒绝」「令牌+Cookie 按 Cookie 规则拒绝」三种组合。
- [x] 2.4 令牌不落地浏览器：签发响应不写 Cookie，前端产物与页面中不出现令牌。验证：断言响应头无 `Set-Cookie`，并在前端构建产物中检索令牌字面量应为 0 命中。

## 4. 会话与流式回答

- [x] 4.1 实现会话与消息接口：新建会话、列出本班会话、读取会话消息（分页）、发送消息。用户消息先行持久化，空白与超长消息返回 400。验证：HTTP 用例断言顺序号连续、分页边界、400 分支。
- [x] 4.2 `gatewayClient` 增加流式对话读取：逐块回调、`[DONE]` 结束、非 200 与流内错误转明确错误、客户端断开即取消上游请求。验证：测试替身分别覆盖正常流、半途断流、非 200、超时四种情形，断言不产生“假流式”整段返回。
- [x] 4.3 实现 `POST /api/classes/{id}/sessions/{sid}/messages` 的 SSE 响应：先检索后生成、增量 `delta`、结束前的 `citations` 与 `done`、保活注释、`Cache-Control: no-store` 与 `X-Accel-Buffering: no`。验证：HTTP 用例逐事件解析并断言事件顺序与字段。
- [x] 4.4 无命中短路与中断语义：无命中时不调用对话模型、只发固定文案与 `no_matches`；客户端断开时已收增量按 `interrupted` 记录。验证：用计数替身断言无命中路径调用次数为 0；用提前 abort 的客户端断言数据库中出现 `interrupted` 且不出现 `complete`。
- [x] 4.5 出处与可核对性：出处由服务端从命中切片生成、编号与 `[n]` 对应、越界编号不再作为引用、每条出处可用来源接口核对。验证：复用第 4 课的越界替身输出与来源核对用例，改为走流式路径断言。
- [x] 4.6 权限与隔离：跨班教师与学生读写会话都按不存在处理、归档后只读、移除成员立即失效。验证：三角色用例逐条断言，并断言响应中不含他班会话内容。
