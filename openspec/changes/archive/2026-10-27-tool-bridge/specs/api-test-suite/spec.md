# Spec Delta

## MODIFIED Requirements

### Requirement: 最低覆盖范围
套件 SHALL 至少覆盖：登录、班级知识库检索、提示词或技能读写、创建会话并发送一条消息（含流式回答与出处落库），以及本课的工具链路：登记工具服务、连接、列出发现的工具、断开，非管理角色被拒，并至少有一条端到端用例覆盖「连接自建工具服务 → 保存引用了 `工具@服务器` 的技能 → 会话提问 → 调用记录中出现一条成功」。

#### Scenario: 覆盖清单可见
- **WHEN** 运行入口完成一次执行
- **THEN** 报告中能逐条看到上述各类用例及其结果

#### Scenario: 流式回答被验证
- **WHEN** 用例发送一条消息并读取流式响应
- **THEN** 断言收到一个以上增量事件、结束事件与出处列表，并核对助手消息已落库

#### Scenario: 工具链路端到端
- **WHEN** 端到端用例连接自建工具服务、绑定技能并提问
- **THEN** 断言收到工具事件、结束元数据含该工具且状态为成功，并能从调用记录接口查到同一条成功的记录

#### Scenario: 非管理角色被拒
- **WHEN** 用例以学生身份请求登记、连接或查看调用记录
- **THEN** 断言返回 403，且不产生任何工具服务或记录
