## 1. 三种检索模式

- [x] 1.1 实现 keyword 模式：MySQL 全文索引查询，限定本班与已发布切片，不调用嵌入模块；验证用仅出现在原文中的中文词命中，并用测试替身断言嵌入网关零调用。
- [x] 1.2 补齐 vector 模式的模式入口与阈值断言：问句嵌入 → Qdrant 带班级过滤查询 → 回表取正文并校验代次 → 丢弃低于 0.35 的候选；验证单测覆盖阈值边界、跨班过滤与代次失效。
- [x] 1.3 实现 hybrid 模式：两路各自绝对过滤后各取前 50 条，按 RRF（k = 60）融合；验证构造数据下两路均命中的切片排在仅单路命中之前，且名次分不被当作相关性阈值。
- [x] 1.4 扩展检索接口契约：`mode`（默认 hybrid）、`top_k`（默认 5、上限 20）、`query` 1–1000 字，`hits` 每项含材料标题、切片序号、字符区间、摘录与定位；验证 400/200 边界，以及请求体携带 `class_id` 时被丢弃而非返回 400。
- [x] 1.5 确定关键字路径的绝对过滤下限并用标注问题集检查低相关命中占比；验证最终取值与依据写入 `docs/verification.md`，不出现明显低相关切片进入前 5 条的情况。
