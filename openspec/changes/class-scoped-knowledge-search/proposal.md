# Proposal

## Why

目前师生只能浏览、下载班级讲义，无法按问题查找相关内容。需要在既有班级权限内检索讲义原文，并提供可核对的文件与位置，避免跨班级泄露和无法验证的结果。

## What Changes

- 以现有班级讲义为知识来源，增加异步文本提取、分块、向量化、索引状态与教师重试入口；新讲义自动排队，历史讲义由班级所有者主动建立索引。
- 支持 PDF、DOC、DOCX、PPT、PPTX、TXT、MD 中可提取的文本。扫描件、图片中的文字本期不做 OCR；无法解析的讲义保留原有下载能力，并明确显示原因。
- 增加当前班级内的语义检索，只向班级所有者和当前成员开放；管理员不自动获得班级内容访问权。归档班级允许读取已有索引，不允许发起新索引或重建。
- 每条结果展示原文片段、讲义名称、来源版本及页码／幻灯片／段落／行号等可验证定位，原文件访问仍走授权接口。
- 采用 PostgreSQL + pgvector 存储索引；增加可配置的嵌入模型适配层，默认使用本地部署服务，故障时明确提示不可检索。
- 仅规划检索和内容溯源，不包含自动生成答案、对话、跨班级知识库、外部网站导入、OCR、智能体、技能或 MCP。

## Capabilities

### New Capabilities

- `knowledge-ingestion`：讲义解析与索引生命周期、异步任务、状态、重试、删除一致性。
- `class-knowledge-search`：带班级授权的语义检索、输入约束、结果状态与界面。
- `knowledge-provenance`：检索片段来源、精确定位、引用读取与失效处理。

### Modified Capabilities

无。当前 `openspec/specs` 尚无已归档主规约；本变更新增能力，延续未归档 `teaching-foundation` 与 `add-text-handouts` 中的授权、文件类型、上传大小及私有下载约束，不改动其完成状态。

## Impact

- 后续实施涉及 Go API、异步 worker、React 班级页面、版本化数据库迁移、Docker Compose 与运维说明；本次只提交 OpenSpec 文档。
- 新增索引任务、文档代次和分块表，以及 pgvector、文本解析器和本地嵌入服务依赖；嵌入模型及维度按配置固定并记录版本。
- 原上传成功不依赖模型响应，原有登录、讲义下载和班级管理在检索服务故障时仍可用。
- 数据库镜像升级必须保持 PostgreSQL 主版本与既有卷兼容，提前备份并验证恢复；不得通过删除数据卷完成迁移。
- 后续验收覆盖跨班级越权、成员撤销、并发删除、来源定位、索引恢复和真实模型中文检索。本提交不声称已实现或通过这些验收。
