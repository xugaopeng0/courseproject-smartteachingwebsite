# Tasks

- [ ] 1.1 验证并锁定 PostgreSQL 18 兼容的 pgvector、解析工具及本地中文嵌入模型版本，记录维度、资源需求、许可证和配置；以真实模型生成查询和文档向量，并用七种格式的中文样例验证工具可运行。
- [ ] 1.2 引入版本化数据库迁移，添加知识文档、索引代次、分块、任务及嵌入配置表和归属约束；在新数据库及既有结构副本上验证迁移、重复启动、跨班级外键拒绝和回滚兼容性。

## 2. 讲义解析与异步索引

- [ ] 2.1 实现 TXT/MD 行号映射与 PDF 按页提取；用 UTF-8 中文、空行、多页、多栏及纯扫描 PDF 验证文本、定位、无文本提示与原文件仍可下载。
- [ ] 2.2 实现 DOCX/PPTX 正文和表格提取、DOC/PPT 隔离转换；用有表格和多幻灯片的样例核对段落、幻灯片顺序以及转换来源标注，验证加密或损坏文件得到明确错误。
- [ ] 2.3 实现保持位置映射的分块与解析资源限制；验证跨页／跨行分块定位不丢失，超时、解压超限及块数超限不会发布残缺索引，宏和外部资源不会执行或读取。
- [ ] 2.4 实现嵌入适配器、配置版本及批量请求；以测试替身覆盖超时、非有限值、零向量、维度错误和重试上限，验证默认本地运行且不自动回退外部服务。
- [ ] 2.5 实现持久化任务队列、租约及占用令牌、分阶段状态、完整代次原子发布；通过中途终止 worker、重复领取、旧 worker 晚到及重建失败测试，确认恢复后无重复有效索引且旧索引可用。
- [ ] 2.6 将新上传排队纳入元数据事务，新增历史讲义建立／重试／重建及状态接口；验证上传不等待模型、重复请求幂等、学生及非所有者无管理权限、错误不暴露路径和凭证。
- [ ] 2.7 联动讲义删除、班级归档与恢复；通过删除和发布并发、物理文件清理失败、归档期间发布和恢复任务测试，验证无内容复活、归档只读且旧索引保留。
- [ ] 2.8 实现嵌入配置变更的完整重建与班级活动配置切换；验证不同维度和模型不混排、重建失败不切换、旧查询模型不可用时明确报错。

## 3. 检索 API 与来源读取

- [ ] 3.1 实现查询输入验证、班级授权、讲义过滤及班级内精确向量排序；覆盖空查询、超长输入、top_k 边界、401/403/404、两班同名文件和其他班级高相似片段，确认拒绝请求不调用模型。
- [ ] 3.2 实现响应前最终权限／来源校验与就绪覆盖状态；阻塞模型请求后移除成员或删除讲义，确认最终响应不泄露内容，并验证无索引、无匹配、部分就绪及模型故障相互区分。
- [ ] 3.3 实现携带版本和位置的结果结构及授权来源接口，复用原下载／PDF 预览入口；核对七种格式原文，验证同名文件、跨班级分块 ID、旧代次、已删除来源及失效会话。
- [ ] 3.4 为检索和来源响应设置不缓存策略，限制日志正文和敏感信息；检查响应头及故障日志，确保不会输出密钥、内部路径、原始向量或讲义正文。
