# 种子材料目录

把课程提供的种子材料放在这里（PDF、DOC、DOCX、PPT、PPTX、TXT、MD），Compose 启动 API 时会按默认窗口策略建立索引，作为内置示例班级的普通讲义。

- 目录会在容器内挂载到 `/data/seeds`（只读）。
- `README` 开头的文件与点号开头的隐藏文件不会被导入；其余受支持格式都会被当作种子材料。
- 导入幂等：重复启动不会产生重复讲义或重复索引任务。
- 把 `SEED_ENABLED` 设为 `false` 可以关闭导入；目录不存在或为空时跳过并记录日志。
- 种子材料不享受任何特殊权限，仍受班级授权、来源校验与删除一致性约束。
